# DevLog Auto-Generator

Application web pour générer automatiquement des DevLogs à partir des commits GitHub.

## Architecture

### Backend (Python/FastAPI) - Layered Architecture
- **controllers/** : Points d'entrée HTTP
- **services/** : Logique métier
- **schemas/** : DTOs et validation
- **models/** : Modèles de données
- **config/** : Configuration
- **utils/** : Utilitaires
- **tests/** : Tests

### Frontend (Angular) - Component-Based Architecture
- **components/smart/** : Composants intelligents
- **components/dumb/** : Composants de présentation
- **services/** : Services Angular
- **models/** : Interfaces TypeScript
- **utils/** : Pipes et utilitaires
